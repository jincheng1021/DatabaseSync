## 三、P0 阻断缺陷（必须修复）

### P0-1 调度服务重启崩溃：时区 aware/naive datetime 比较抛 TypeError ✅ 已修复（2026-10-11）
- **位置**：`backend/app/services/scheduler_service.py:112-113`（登记）与 `:115-125`（补偿检查）——已人工复核确认
- **问题**：`_register` 存入的 `next_fire_at` 是**带时区** ISO 字符串；重启后 `_misfire_check` 用 `datetime.fromisoformat(nfa)`（aware）与 `datetime.now()`（naive）做 `<=` 比较，抛 `TypeError`，而该处只捕获 `ValueError`。**只要存在任意一条启用的调度计划，应用重启即无法完成启动**（异常穿透 reload_all → start → lifespan）。
- **修复**：`_misfire_check` 按解析结果的自身时区取 `now`（aware/naive 各自对齐），异常捕获扩为 `(ValueError, TypeError)`；新增 3 条回归用例（aware 过期补偿 / aware 未期不触发 / reload_all 重启恢复全路径）。
