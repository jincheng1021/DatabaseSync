# 用户手册

> 版本 0.5.0-M5 ｜ 面向数据库管理员与运维人员。术语见文末术语表（§14）。

## 1. 快速上手

1. **登录**：首次访问进入管理员引导（bootstrap，一次性设置），此后使用账号密码登录；连续 5 次失败锁定 15 分钟。
2. **录入数据源**：数据源页 → 新建 → 填写主机/端口/账号 → 保存后点「预检」。预检全绿（或有提示项）方可用于建任务。
3. **新建任务**：任务页 → 新建向导（四步）：数据源 → 映射（范围/改名/过滤） → 策略（限流/攒批/开关） → 确认。
4. **发起初始化**：草稿任务点「发起初始化」；目标库非空时走「清空重建」（需手动输入目标库名二次确认）。
5. 初始化完成后自动进入增量（init_plus_cdc 模式）；在详情页可暂停/恢复/停止增量。

## 2. 三类任务模式

| 模式 | 说明 | 主要状态路径 |
| --- | --- | --- |
| 初始化+持续增量 | 一次初始化，此后 binlog 实时追平 | draft → 初始化中 → 增量运行中 ⇄ 暂停 |
| 定时全量 | 保存即就绪，按 cron 定时全量覆盖 | 保存即空闲 → 触发（目标空=初始化 / 非空=重刷） |
| 仅备份 | 轻量路径，定时/手动导出备份 | 空闲 ⇄ 备份中 |

## 3. 任务详情页

- **概览**：当前状态、位点（GTID/file+pos）、延迟曲线（ECharts，1 秒级推送，橙色虚线为告警阈值）、事件统计；
- **调度**：cron 模板/手输 + 时区 + 未来 5 次触发预览；重叠策略（跳过/排队）与停机错过补偿（补跑/跳过）；
- **策略**：全量并发/批大小、增量提交批、两级限流、大事务阈值、安全网备份、孤儿清理开关、手动清理/校验入口；
- **映射**：表勾选、改名、列过滤、行过滤条件构建器、无主键表降级选择、触发器迁移开关（红色风险确认）。运行中禁止修改映射——请先暂停。

## 4. DDL 待决策

增量/全量期间源库发生 DDL：任务进入「DDL 待决策」，顶部出现预警卡。两种决策：

- **执行**：目标库应用该 DDL（增量路径）或受影响表从结构阶段重做（全量路径）；
- **跳过**：目标库不变更（表结构可能漂移，校验兜底）。

勾选「记住选择」后，同类 DDL 自动决策（任务级规则持久化，重启生效），全部落审计。

## 5. 校验与修复

任务策略页/详情页发起校验：

- **行数校验**：精确 COUNT，全表 100% 对账；
- **checksum**：主键分块 CRC32，含孤儿行检测；
- **行级 diff**：不一致行两端对照展示（敏感列脱敏），可单表发起**覆盖修复**（源库当前值覆盖 + 目标多余删除；二次确认；行过滤子集表禁用删除类修复）。

## 6. 备份与恢复

- **导出**：备份页发起（整库/选表/仅结构），产物 gzip + SHA-256，文件头含会话环境声明（字符集/时区/GTID/版本）；
- **恢复三步向导**：选目标 → 预检（失败项阻断） → 确认执行。目标库非空=覆盖式恢复，需手动输入目标库名确认；恢复期间自动暂停关联任务、完成后自动恢复；
- 恢复中断后目标库标记「恢复未完成」，指引整体重跑（不做断点续传）。

## 7. 告警与通知

顶栏铃铛实时弹出（WS）；设置页配置 Webhook（企业微信群机器人 text）与 SMTP 邮件，可「测试发送」；静默期防重复告警。典型告警：延迟超阈值、大事务（E8）、位点失效、DDL 拦截、目标写失败、校验不一致率超限。

## 8. 执行历史

全局 run 列表：类型/状态筛选（URL 持久化，可分享）、分页、下钻查看运行报告与表级明细；所有状态迁移以 run_type=state_change 记录可追溯。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| FTWRL 超时 | 源库有长事务/长查询；处理后在低峰重试；GTID+全 InnoDB 库可走无锁取位 |
| 位点失效（needs_reinit） | binlog 被清理/停机超保留期；一键重刷或重新初始化 |
| 无主键表未同步 | 事件丢弃计数并告警；补主键或改为定时 checksum 降级比对 |
| 目标写失败 3 次 | 任务转 error；修复目标库后人工恢复/重试 |
| WS 断线 | 顶栏横幅提示，自动指数退避重连，恢复后快照对齐 |

## 10. 术语表

| 术语 | 含义 |
| --- | --- |
| CDC | Change Data Capture，解析 binlog 获取行级变更 |
| 位点 | binlog 消费进度坐标：GTID 集合，或文件名+偏移量 |
| 一致位点 P0 | 全量开始时经 FTWRL（或一致快照）获取的坐标，全量后增量从此续接 |
| 幂等写 | 同一变更重复执行结果不变（REPLACE INTO / 按主键 DELETE） |
| at-least-once | 每事件至少投递一次，配合幂等写达到效果上的 exactly-once |
| 孤儿行 | 目标库存在而源库已不存在的行，重刷后需清理 |
| 重刷缓存队列 | 全量重刷期间暂存涉及表增量事件的内存+磁盘混合队列 |
| 子集同步 | 按 WHERE 条件只同步部分行；禁用孤儿清理 |
| 退出范围 UPDATE | 行过滤表上使行离开过滤条件的更新，增量时转 DELETE 防越界污染 |
| 降级比对 | 无主键等表改用定时 checksum + 差异覆盖 |
| FTWRL | FLUSH TABLES WITH READ LOCK；秒级全局读锁取一致位点 |
| 结构指纹 | SHOW CREATE TABLE 归一化哈希，检测全量期源库 DDL |
| 两级限流 | 任务级令牌桶 + 全局总闸 |
| 背压 | 队列高水位暂停上游拉取，防内存溢出 |
