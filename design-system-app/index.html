设计原则 Design Principles

源于方案的交互约定（§6.3）：危险操作必须二次确认、时间统一本地时区、延迟数值按绿 / 黄 / 红三档着色、WS 断线全局横幅提示。

01 · 数据先行 让数据自己说话 位点、SHA-256、DDL 原文、延迟秒数等关键数据始终直接可见；数字一律等宽字体，杜绝装饰干扰。
02 · 克制的工程美学 层级靠明度，不靠阴影 深色画布上以 1px 发丝线与三级明度梯度区分层级；紫色仅用于操作与焦点，每页信号色不超过一种。
03 · 状态可见性 任何状态都不允许静默 任务 12 种状态机状态、预检通过 / 警告 / 失败三态、WS 连接状态均有明确视觉表达；危险操作一律红色 + 二次确认。
04 · 4px 栅格秩序 一切间距皆有刻度 间距、字号、圆角全部落在 4px 基准的刻度上；表格行高 40px、侧边栏 240px、内容区最大 1280px 保持全局节奏一致。

02 · 颜色体系 Color System

深色为默认模式（监控大屏场景），亮色按变量 Light 模式一键切换；所有色值均已录入 Semantic Color 变量集。层级靠三级明度梯度 + 1px 发丝线表达，禁止彩色阴影。

文字色 · 三级层级

语义色 · 使用规则

每行展示暗色模式的色彩样本；亮色模式色值并列标注。所有语义色组件同时录入变量集，双模式自动换算。

Accent · 操作 / 焦点 #7C3AED 主按钮、焦点环、选中态、链接 禁止用于装饰
Info · 链路 / 数据 #22D3EE / 亮 #0AB5D9 数据链路标识、DDL 代码块、位点高亮 与 Accent 混用
Success · 运行 / 通过 #10B981 / 亮 #059869 增量运行中、预检通过、校验一致 ——
Warning · 待处理 #F59E0B / 亮 #C7790C DDL 待决策、延迟接近阈值、已知限制提示 ——
Error · 失败 / 危险 #F43F5E / 亮 #D93841 任务失败、熔断、危险操作按钮（清空重建 / 删除） 禁止做强调色

状态机 · 色彩映射

对应方案 §10 任务状态机的 12 种状态：状态一律以「色点 + 文字」的胶囊表达，禁止仅用颜色区分（可访问性）。
